# Gauntlet

A research template for AI agents. Every claim in the report shows how it was checked.

1. Copy this repo into a new folder.
2. Write your question in `AGENTS.md`.
3. Ask your agent to research it. The result is `report.md`.

The agent follows `.skills/gauntlet/SKILL.md`; its scripts check quotes, numbers and tests.
Needs Python 3.10+. Optional: `OPENALEX_API_KEY` for wider literature search.
